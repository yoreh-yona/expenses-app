איך יוצרים מפתח?

  2. Token name: expenses-app, Expiration: הארוך ביותר
  3. Repository access: Only select repositories ← expenses-app
  4. Permissions ← Repository: Variables = Read and write, Actions = Read and write
  5. Generate token, העתק והדבק כאן
