# הוצאות אישיות

אפליקציית ווב (PWA) לניהול הוצאות אישיות בעבודה והפקת דוח חודשי חתום להנהלת חשבונות.

- הזנת הוצאה + צילום/סריקת קבלה
- תקופת דוח: 26 לחודש הקודם – 25 לחודש
- א.ש.ל לפי שעות, ללא קבלה
- דוח Word מתבנית + חתימה + PDF קבלות, ושליחה דרך תפריט השיתוף

הנתונים נשמרים בטלפון בלבד (IndexedDB).

כתובת: https://yoreh-yona.github.io/expenses-app/
